# Задание 12 (docs/shared.pdf, 20-11-2026) — абстрактный класс, полиморфизм, документация

Каждая часть — самостоятельный проект; каждый класс — отдельный модуль (`.h` + `.cpp`).

| Часть | Папка | Что сделано |
|---|---|---|
| 12.I п.1 | `Task12_1/robot.h/cpp` | абстрактный `Robot` с чистой виртуальной `move()`; создать объект нельзя, не переопределивший `move()` потомок тоже остаётся абстрактным |
| 12.I п.2 | `Task12_1/quadruped_robot.h/cpp` | `QuadrupedRobot` — первый конкретный класс, `move()` = шаг галопом |
| 12.I п.3 | `Task12_1/cargo_quadruped_robot.h/cpp` | `CargoQuadrupedRobot` — своя `move()`: шаг с расходом, зависящим от массы груза |
| 12.I п.4 | `Task12_1/autonomous_cargo_quadruped_robot.h/cpp` | `AutonomousCargoQuadrupedRobot` — 4-я ступень той же цепочки, своя `move()`: автономный марш до исчерпания запаса хода |
| 12.I п.5 | `Task12_1/main.cpp` | массив представителей каждого класса: полиморфный вызов `move()` и три случая НЕ-полиморфного (невиртуальный метод, срезка объекта при массиве по значению, недоступные свои методы через `Robot*` + `dynamic_cast`) |
| 12.II | `Task12_2/clangdoc/` | документация, сгенерированная **из комментариев в коде** (`clang-doc`, формат md) по 4 классам иерархии |

## Сборка и запуск

```
cmake -S homeworks/Task12/Task12_1 -B homeworks/Task12/Task12_1/build -G "MinGW Makefiles"
cmake --build homeworks/Task12/Task12_1/build
homeworks\Task12\Task12_1\build\robot.exe
```

Собрано MinGW (g++ 6.3.0, `-Wall -Wextra`) без предупреждений.

`Task12_1/not_allowed_example.cpp` в сборку не входит: он доказывает, что класс с
`move() = 0` действительно абстрактный и что protected/private часть недоступна
постороннему коду, — обязан не компилироваться.

Подробности: [`Task12_1/README.md`](Task12_1/README.md) (иерархия и полиморфизм),
[`Task12_2/README.md`](Task12_2/README.md) (чем и как генерировалась документация,
её ограничения).
